Подключение к эмулятору

Откройте ссылку из запуска сервера или вставьте ключ доступа. На другом устройстве ссылку можно получить кнопкой «Подключить устройство».

Доступ с другого устройства

Компьютер с сервером должен оставаться включённым. Для телефона используйте сетевой адрес, ту же Wi-Fi сеть или VPN. Все устройства управляют одной машиной.

Адрес 127.0.0.1 работает только на этом компьютере. Для домашней сети обычно нужен 192.168.… . Скопируйте полную ссылку вместе с ключом.

Последние ARM-инструкции


Цифровые входы / GPIO
80 выводов, уровни 0 и 1. Штатная прошивка настраивает GPIO 46 на спадающий фронт. Это не подтверждённое назначение кнопки.
После настройки GPIO: задайте 1 → 0, затем нажмите «Запуск», чтобы обработать прерывание.
Аналоговые входы / АЦП
Заданные тестовые значения, не измерения с браслета. Канал 4 выбирает аппаратную ревизию при загрузке.
600 → ревизия 4; 720 → ревизия 3. Меняйте до инициализации АЦП. Неизвестный канал остановит выполнение.
Частотные профили


Явные замены оборудования / HLE
Ядро, планировщик и обработчики выполняются из прошивки. Часть аппаратных операций заменена моделью. Здесь последние 16 вызовов; полный журнал — в отчёте.
